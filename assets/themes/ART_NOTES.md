# Seasonal and Aurora artwork

Created with the built-in image-generation tool. Original PNGs and optimized
WebP files are kept here; the game loads WebP.

Prompt set:

- `halloween-decor`: transparent edge decoration, orange/bone/black paper-cut
  castles, bats, pumpkins and leaves; no masks, text, UI or central obstruction.
- `newyear-decor`: transparent art-deco gold/burgundy edge decoration, a partial
  midnight clock, ornaments, ribbons and restrained confetti; clear central area.
- `aurora-frost`: opaque polar navy wallpaper, mint/blue aurora, distant snowy
  mountains and faceted ice crystals; quiet dark central area, no text or UI.

The calendar art is independent of the theme wallpaper. CSS supplies small,
non-interactive animated bats/snow/confetti, a gala clock and a subtle aurora
overlay. Low-quality/reduced-motion modes stop decorative movement.
